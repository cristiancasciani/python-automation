Ordo tidies a messy folder
and turns PDF invoices into Excel.

One command sorts 61 files into folders, sets duplicates aside, reads 10 supplier invoices (Italian and English), renames them as date_supplier_number.pdf, flags the ones that need a human check and writes a report. Below is a real run, replayed.

~ — ordo

Organise
Files sorted by type (and month if you want). Duplicates found by content, not by name.

    
Rename
Bulk rename with patterns like {date}_{name} or photo_{n:03}, with a preview.

    
Read invoices
Supplier, number, date, VAT ID, net, VAT and total from PDFs. Totals are cross-checked.

    
Report & undo
HTML + Excel report. Nothing changes without --apply, and ordo undo puts everything back.

  


  
Also with a window

  
For people who never open a terminal: the same engine with a simple Tkinter interface — preview, apply, undo.
